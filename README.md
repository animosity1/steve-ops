# STEVE OPS

Daily ops console for Steve Will Do It, run by operator **@optikz1**.

Live: https://animosity1.github.io/steve-ops/

Not a pitch deck. A working board: open loops, challenge command, money promises, morning brief, paste-ready drafts.

## Open locally

```bash
cd steve-ops
python3 -m http.server 8787
# visit http://localhost:8787
```

Works offline. State persists in localStorage.

## Tabs

| Tab | Purpose |
|-----|---------|
| **HOME** | HUD: Chicago clock, FIRE count, challenge days, ledger OPEN |
| **BOARD** | Kanban FIRE / ACTIVE / PARKED / DONE |
| **WAR ROOM** | Countdown to Sep 25, 10 winner slots, promo checklist |
| **LEDGER** | Public money promises |
| **BRIEF** | One-click daily brief + copy |
| **DRAFTS** | Paste-ready templates |

Keyboard `1`-`6` switches tabs.
